> **Goal:** recognize the most common letter-substitution cipher on sight and decode it three different ways. ROT13 appears in countless CTFs as a "wrapper" layer around real challenges.

---

## 1. Understanding the challenge
You get a ciphertext where letters are shifted by 13 positions (ROT13 is its own inverse — applying it twice returns the original). Telling signs: the text is English-shaped, keeps its spacing and punctuation, and often contains `pico` scrambled inside what should be the flag prefix.

## 2. Tools
- CyberChef (ROT13 recipe)
- `tr` in the shell
- Python one-liner

## 3. Recon
```bash
echo 'cvpbPGS{...}' | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```
The `p` -> `c` style shift pattern in `cvpbPGS` is the giveaway that the flag prefix was ROT13'd too.

## 4. Solution Path
Any one of these works — do all three once so the technique is permanent:

```bash
# 1) tr: shift both cases by 13 (tr wraps automatically)
echo '<ciphertext>' | tr 'A-Za-z' 'N-ZA-Mn-za-m'

# 2) Python
python3 -c "import codecs;print(codecs.decode('<ciphertext>','rot13'))"
```
```text
3) CyberChef: https://gchq.github.io/CyberChef/
   Recipe: ROT13 -> Amount: 13 -> paste ciphertext in Input
```
Output is the flag in cleartext.

## 7. Write It Up (report-ready paragraph)
> "The intercepted string used ROT13, a Caesar variant with a fixed shift of 13 that provides no security (keyspace of 1, self-inverse). Decoding required no secret material at all (<evidence>). In report terms, monoalphabetic shifts are obfuscation, not encryption; any data 'protected' this way must be treated as plaintext in threat models."

## 8. Lessons
- `cvpbPGS` -> `picoCTF` — learn this mapping by eye; it flags ROT13 instantly.
- `tr 'A-Za-z' 'N-ZA-Mn-za-m'` is worth memorizing; it works in any shell with zero installs.
- Self-inverse ciphers (ROT13, XOR with the same key) decode and encode with the same operation.
